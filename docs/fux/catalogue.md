# Catalogue of Fux's strict-counterpoint exercises

One row per exercise (illustrative fragments are omitted). Pages: 1725 print, from the dataset
metadata (printed page = scan file number − 8). "Written by" says who writes the exercise in the
dialogue: Josephus (the pupil, i.e. the player, decision D12 as revised) or Aloysius (a model
the pupil studies). "What is new" paraphrases what is taught at that exercise or just before
it; "nothing new" means the exercise repeats the lesson in another mode or position.

Confidence: two voices verified in the 1725 scans; three and four voices read in Mann (pages
given as "Mann n"), with the 1725 page taken from the dataset. "inferred" marks an attribution
the dialogue implies without stating.
