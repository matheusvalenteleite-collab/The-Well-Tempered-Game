# The literature, shared by all sessions (D161)

One list, so that the sessions' reviews do not duplicate each other. Every entry is checked before it is
listed (author, title, venue, year, pages where they matter); nothing is listed from memory alone. Each
session adds its own rows and leaves the others' alone. The owner chooses what is read.

**Tier.**
- **1:** read now; it answers a question the session is working on.
- **2:** consult for a named question.
- **3:** known and judged not relevant, with the reason, so that it is not proposed again.

**Status.** One of: proposed / chosen by the owner / read / not available.

**Access.** One of: open (with the place) / library / not found.
