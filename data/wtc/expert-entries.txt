# THE EXPERT ENTRIES (D493): every entry of every subject in the 48 fugues, as the published analyses
# give them. The game's entries (data/touch/pieces.json) are built from this table (tools/touch/expert.ts
# placeExpert, run by tools/touch/extract.ts); docs/wtc/entries/EXPERT-AUDIT.md says what changed and why.
#
# Sources (keys used below):
#   P  Ebenezer Prout, Analysis of J. S. Bach's Forty-Eight Fugues, ed. Louis B. Prout (London: Ashdown, 1910)
#      (archive.org analysisofjsbach00prouuoft). Bars as here: the first complete bar is bar 1.
#   I  Frederick Iliffe, The Forty-Eight Preludes and Fugues of John Sebastian Bach Analysed for the Use of
#      Students (London: Novello, 1897): a bar-by-bar table of every entry (archive.org fortyeightprelud00ilifuoft).
#   B  Busoni's edition (Schirmer, 1894; docs/wtc/readings/busoni/): his entry labels (S A T B, turned letters for
#      inversion, V variation, D diminution, augmentation brackets) and footnotes.
#   L  Ledbetter, Bach's Well-tempered Clavier (Yale, 2002): data/wtc/ledbetter-claims.txt, later-subjects.json.
#   G  the game's own entry, which no source names and none denies: kept (never invented, never dropped unseen).
#
# Grammar: "== id | sources" opens a fugue; then one entry a line:
#   BAR[+Q] VOICE [flags] [; source keys] [# note]
#   BAR: the bar as the sources number it; +Q: quarter-notes after the barline where the start is known.
#   VOICE: S A T B (four voices), S A B (three), S1 S2 A T B (five), U L (two).
#   flags: ans (the answer), inv (inverted), aug (augmented), dim (diminished), part (partial: only the head
#   or part of it), mod (modified: notes changed, still an entry), t2 / t3 (the second / third subject),
#   len=N (a first statement's length in quarter-notes, for a later subject), n=N (an entry N notes long).
#   "multi" after the sources marks a fugue of several subjects (its flags read SUBJECT 1, 2, 3).
#   "% text" lines record where the sources disagree.
