# Source: Bach, cantata "Widerstehe doch der Sünde", BWV 54

- **Files** (`imslp/`): for each movement 54.1, 54.2, 54.3 a compressed MusicXML (`.mxl`) and a MIDI
  file, from the engraving files supplied by the owner (27 October 2026) as IMSLP #751695: the edition by
  **Ramon Casadesus-Masanell** (2021, MuseScore), listed on the work page
  https://imslp.org/wiki/Widerstehe_doch_der_S%C3%BCnde,_BWV_54_(Bach,_Johann_Sebastian) as
  `PMLP149300-Widerstehe_doch_der_S_nde_BWV_54_EngravingFiles.zip` ("Engraving files (MuseScore)", with
  the three movements' PDFs), uploaded by Casadesus, 2021-12-18. (The `.mscz` files were not kept: the
  MusicXML and MIDI hold the same notes. The file number itself could not be opened here: IMSLP's file
  pages redirect to a bot check; the licence below is the work page's for that entry, read through
  IMSLP's API on 27 October 2026.)

- **What it holds.** 54.1 Aria (E♭ major, 4/4, 55 bars; the da capo written as a direction, played by
  the MIDI): Violino I, Violino II, Viola I, Viola II, Alto, Continuo, and a piano reduction. 54.2
  Recitativo (19 bars): Alto, Continuo. 54.3 Aria "Wer Sünde tut, der ist vom Teufel" (2/2, 72 bars, a
  four-part fugue): Violino I.II. (in unison), Viola I.II. (in unison), Alto, Continuo, and a piano
  reduction. Lyrics included (not read).
- **Read by** `tools/touch/more-bach.ts` (D341, through `tools/touch/musicxml.ts`): `bwv54-1` (as
  written, 55 bars, the da capo not taken; six voices, the alto offered first) and `bwv54-3` (four
  voices, the alto offered first); the piano reduction left out; the recitative left out (a recitative
  fits a one-line game poorly). The MusicXML's attacks are in the edition's own MIDI: 100% (54.1; the
  MIDI plays the da capo besides) and 99.9% (54.3).
- **Checked** against CCARH's MuseData (bitbucket.org/musedata/bach `bg/cant/0054/stage1`, never
  proofread; read for this private check only, never shipped): the same parts and bars, 55 in each of
  movement 1's six parts and 72 in each of movement 3's four.
